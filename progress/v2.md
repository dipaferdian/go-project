### Package

# 2. Struct, Methods, dan Receivers

## 2.1. Struct

- [x] Memahami konsep Struct.
- [x] Membuat Struct.
- [x] Menentukan Struct Fields.
- [x] Membuat Struct Instance.
- [x] Mengakses Struct Fields.
- [x] Mengubah nilai Struct Fields.
- [x] Menggunakan Struct sebagai representasi sebuah objek.

### Fungsi Struct

Struct digunakan untuk menggabungkan beberapa field dengan tipe data berbeda ke dalam satu tipe data.

Contoh:

```go
type User struct {
    ID    int
    Name  string
    Email string
}
```

Membuat instance:

```go
user := User{
    ID:    1,
    Name:  "John",
    Email: "john@example.com",
}
```

Mengakses field:

```go
fmt.Println(user.Name)
fmt.Println(user.Email)
```

Mengubah field:

```go
user.Name = "David"
```

### Kegunaan Struct

Struct berguna untuk:

- Merepresentasikan data user.
- Merepresentasikan produk.
- Merepresentasikan transaksi.
- Menyimpan konfigurasi aplikasi.
- Menyimpan state suatu proses.

## 2.2. Methods

- [x] Memahami konsep Method.
- [x] Membuat Method.
- [x] Menghubungkan Method dengan Struct.
- [x] Memanggil Method melalui Struct Instance.

### Fungsi Method

Method adalah function yang memiliki receiver dan terhubung dengan suatu tipe data.

Contoh:

```go
type User struct {
    Name string
}

func (user User) GetName() string {
    return user.Name
}
```

Pemanggilan:

```go
user := User{
    Name: "John",
}

fmt.Println(user.GetName())
```

Perbedaan Function dan Method:

**Function:**

```go
func GetName(user User) string {
    return user.Name
}
```

**Method:**

```go
func (user User) GetName() string {
    return user.Name
}
```

Function dipanggil secara langsung, sedangkan Method dipanggil melalui receiver.

---

## 2.3. Receivers

- [x] Memahami Receiver.
- [x] Value Receiver.
- [x] Pointer Receiver.
- [x] Perbedaan Value Receiver dan Pointer Receiver.

### Value Receiver

Value Receiver menerima salinan nilai dari Struct.

```go
func (user User) UpdateName() {
    user.Name = "David"
}
```

Perubahan pada salinan tersebut tidak mengubah Struct asli.

### Pointer Receiver

Pointer Receiver menerima pointer ke Struct.

```go
func (user *User) UpdateName() {
    user.Name = "David"
}
```

Perubahan akan memengaruhi Struct asli.

### Perbandingan

| Value Receiver                                         | Pointer Receiver                           |
| ------------------------------------------------------ | ------------------------------------------ |
| `(user User)`                                          | `(user *User)`                             |
| Menerima salinan Struct                                | Menerima pointer Struct                    |
| Tidak mengubah Struct asli melalui receiver            | Dapat mengubah Struct asli                 |
| Cocok untuk operasi yang tidak perlu memodifikasi data | Cocok untuk operasi yang memodifikasi data |

### Fungsi Pointer

Pointer menyimpan alamat memori dari suatu variabel.

Contoh:

```go
func main() {
    number := 100

    pointer := &number

    fmt.Println(number)
    fmt.Println(pointer)
```

### Address Operator (`&`)

Digunakan untuk mendapatkan alamat memori variabel.

```go

```

### Dereference Operator (`*`)

Digunakan untuk mengakses nilai yang tersimpan pada alamat memori tersebut.

```go
fmt.Println(*pointer)
```

Mengubah nilai melalui Pointer:

```go
*pointer = 200
```

Nilai `number` juga berubah menjadi `200`.

### Kegunaan Pointer

- Mengubah data asli dari Function.
- Menghindari penyalinan Struct berukuran besar.
- Digunakan pada Pointer Receiver.
- Digunakan dalam pengelolaan Shared Data.

# 5. Defer

- [x] Memahami konsep Defer.
- [x] Menggunakan `defer`.
- [x] Multiple Defer.
- [x] Memahami urutan LIFO.
- [x] Defer untuk Cleanup.
- [x] Defer bersama Mutex.
- [x] Defer bersama WaitGroup.

### Fungsi Defer

`defer` digunakan untuk menunda eksekusi suatu Function sampai Function yang membungkusnya selesai.

Contoh:

```go
func main() {
    defer fmt.Println("Second")
    fmt.Println("First")
}
```

Output:

```text
First
Second
```

### Multiple Defer

Jika terdapat beberapa `defer`, eksekusinya menggunakan prinsip LIFO (Last In, First Out).

```go
func main() {
    defer fmt.Println("A")
    defer fmt.Println("B")
    defer fmt.Println("C")
}
```

Output:

```text
C
B
A
```

### Defer pada Mutex

```go
mu.Lock()
defer mu.Unlock()
```

Dengan demikian, Unlock akan dijalankan ketika Function selesai.

### Defer pada WaitGroup

```go
func worker(wg *sync.WaitGroup) {
    defer wg.Done()

    fmt.Println("Working...")
}
```

`wg.Done()` dipanggil ketika Function selesai.

# 6. Panic dan Recover

## 6.1. Panic

- [x] Memahami konsep Panic.
- [x] Menggunakan `panic()`.
- [x] Memahami penghentian alur normal Function.
- [x] Memahami proses Stack Unwinding.
- [x] Memahami hubungan Panic dengan Defer.

### Fungsi Panic

Panic digunakan ketika program mengalami kondisi yang membuat eksekusi normal tidak dapat dilanjutkan.

Contoh:

```go
func process() {
    fmt.Println("Start")

    panic("something went wrong")

    fmt.Println("End")
}
```

`fmt.Println("End")` tidak akan dieksekusi karena terjadi Panic.

Namun, Function yang memiliki `defer` tetap menjalankan Defer ketika Panic berlangsung.

## 6.2. Recover

- [x] Memahami konsep Recover.
- [x] Menggunakan `recover()`.
- [x] Menangkap Panic.
- [x] Menggunakan Recover di dalam Defer.
- [x] Melanjutkan eksekusi setelah Panic berhasil ditangani.

Contoh:

```go
func process() {
    defer func() {
        if result := recover(); result != nil {
            fmt.Println("Recovered:", result)
        }
    }()

    fmt.Println("Task started")

    panic("task failed")
}

func main() {
    process()

    fmt.Println("Main continues")
}
```

Output:

```text
Task started
Recovered: task failed
Main continues
```

### Hubungan Defer, Panic, dan Recover

| Fitur       | Fungsi                                       |
| ----------- | -------------------------------------------- |
| `defer`     | Menunda eksekusi Function                    |
| `panic()`   | Menghentikan alur normal                     |
| `recover()` | Menangkap Panic ketika dipanggil dalam Defer |

## 7.2. WaitGroup

Package: `sync`

- [x] Memahami `sync.WaitGroup`.
- [x] `wg.Add(n)`.
- [x] `wg.Done()`.
- [x] `wg.Wait()`.
- [x] Menggunakan WaitGroup bersama Goroutine.
- [x] Menggunakan Pointer pada WaitGroup.
- [x] Menggunakan `defer wg.Done()`.
- [x] Memahami Counter WaitGroup.
- [x] Memahami hubungan jumlah Add dan Done.

### Fungsi WaitGroup

WaitGroup digunakan untuk menunggu sejumlah Goroutine menyelesaikan pekerjaannya.

Contoh:

```go
func worker(
    name string,
    wg *sync.WaitGroup,
) {
    defer wg.Done()

    fmt.Println(name, "started")

    time.Sleep(2 * time.Second)

    fmt.Println(name, "finished")
}

func main() {
    var wg sync.WaitGroup

    wg.Add(3)

    go worker("Task 1", &wg)
    go worker("Task 2", &wg)
    go worker("Task 3", &wg)

    wg.Wait()

    fmt.Println("All tasks completed")
}
```

### Method WaitGroup

| Method   | Fungsi                           |
| -------- | -------------------------------- |
| `Add(n)` | Menambahkan counter              |
| `Done()` | Mengurangi counter sebanyak satu |
| `Wait()` | Menunggu counter menjadi nol     |

### Alur Counter

```text
wg.Add(3)  -> Counter = 3

Task 1 selesai -> Counter = 2
Task 2 selesai -> Counter = 1
Task 3 selesai -> Counter = 0

wg.Wait() selesai
```

Catatan: `WaitGroup` digunakan untuk sinkronisasi, bukan untuk mengirimkan hasil dari Goroutine.

## 7.3. Mutex

Package: `sync`

- [x] Memahami Mutex.
- [x] `sync.Mutex`.
- [x] `Lock()`.
- [x] `Unlock()`.
- [x] Menggunakan Mutex pada Struct.
- [x] Menggunakan Mutex dalam Method.
- [x] Menggunakan Pointer Receiver bersama Mutex.
- [x] Menggunakan Defer untuk Unlock.

### Fungsi Mutex

Mutex digunakan untuk membatasi akses bersamaan terhadap Shared Data.

Contoh:

```go
type Inventory struct {
    Stock int
    mu    sync.Mutex
}

func (inventory *Inventory) AddStock(amount int) {
    inventory.mu.Lock()
    defer inventory.mu.Unlock()

    inventory.Stock += amount
}
```

### Lock

```go
inventory.mu.Lock()
```

Mengunci bagian kode sehingga Goroutine lain yang menggunakan Mutex yang sama harus menunggu.

### Unlock

```go
inventory.mu.Unlock()
```

Melepaskan Lock agar Goroutine lain dapat mengakses bagian yang dilindungi.

## 7.4. Race Condition

- [x] Memahami konsep Race Condition.
- [x] Memahami Shared Data.
- [x] Memahami akses data secara bersamaan.
- [x] Memahami mengapa Mutex diperlukan.
- [x] Menggunakan Mutex untuk melindungi Shared Data.

### Fungsi Race Condition

Race Condition terjadi ketika hasil program bergantung pada urutan akses bersamaan terhadap data, tanpa synchronization yang tepat.

Contoh masalah:

```go
type Counter struct {
    Value int
}

func (counter *Counter) Increment() {
    counter.Value++
}
```

Jika beberapa Goroutine menjalankan `Increment()` secara bersamaan, operasi tersebut dapat menyebabkan Race Condition.

Solusi:

```go
type Counter struct {
    Value int
    mu    sync.Mutex
}

func (counter *Counter) Increment() {
    counter.mu.Lock()
    defer counter.mu.Unlock()

    counter.Value++
}
```

# 8. Channel

Channel merupakan mekanisme komunikasi antar-Goroutine.

## 8.1. Dasar Channel

- [x] Memahami konsep Channel.
- [x] Membuat Channel menggunakan `make()`.
- [x] Mengirim Data.
- [x] Menerima Data.
- [x] Menggunakan Operator `<-`.
- [x] Menggunakan Channel bersama Goroutine.
- [x] Menutup Channel dengan `close()`.

Contoh:

```go
func main() {
    ch := make(chan int)

    go func() {
        ch <- 100
    }()

    value := <-ch

    fmt.Println(value)
}
```

### Send Operation

```go

```

Mengirim nilai 100 ke Channel.

### Receive Operation

```go
value := <-ch
```

Menerima data dari Channel.

### Close

```go
close(ch)
```

Menutup Channel agar tidak ada pengiriman data baru.

Channel yang ditutup masih dapat dibaca selama buffer-nya masih memiliki data.

---

- [x] Memahami Unbuffered Channel.

## 8.3. Buffered Channel

- [x] Memahami Buffered Channel.
- [x] Membuat `make(chan int, n)`.

- [x] Memahami Perilaku ketika Buffer Penuh.

| Unbuffered                           | Buffered                                                      |
| ------------------------------------ | ------------------------------------------------------------- |

# 9. Select Statement

- [x] Memahami Select.
- [x] Select dengan Multiple Cases.
- [x] Receive Operation.
- [x] Send Operation.
- [x] Default Case.
- [x] Select dengan For Loop.
- [x] Menggunakan Select untuk beberapa Channel.
- [x] Memahami Blocking dan Non-blocking.
- [x] Menggunakan `value, ok`.
- [x] Mengatur Channel menjadi `nil`.
- [x] Select bersama Context.
- [x] Select bersama Timer.

### Fungsi Select

`select` digunakan untuk menunggu beberapa operasi komunikasi Channel sekaligus.

Contoh:

```go
select {
case value := <-ch1:
    fmt.Println(value)

case value := <-ch2:
    fmt.Println(value)
}
```

Jika beberapa operasi siap secara bersamaan, Go memilih salah satunya secara pseudo-random.

### Default

```go
select {
case value := <-ch:
    fmt.Println(value)

default:
    fmt.Println("No data available")
}
```

Default membuat Select tidak menunggu ketika tidak ada operasi yang siap.

### Select dengan For

Select dapat digunakan di dalam Loop untuk terus memproses beberapa Channel.

```go
for {
    select {
    case value := <-ch1:
        fmt.Println(value)

    case value := <-ch2:
        fmt.Println(value)
    }
}
```

### Channel Nil

Channel bernilai `nil` tidak pernah siap untuk operasi Send atau Receive.

Mengubah Channel menjadi nil dapat digunakan untuk menonaktifkan case tertentu dalam Select.

### Select dan Timer

```go
select {
case <-ctx.Done():
    fmt.Println("Worker stopped")

case <-time.After(3 * time.Second):
    fmt.Println("Worker completed")
}
```

`time.After()` mengembalikan Channel, sehingga harus menggunakan Receive Operator (`<-`).

### Fungsi Middleware

Middleware adalah komponen yang berada di antara HTTP Request dan Handler utama.

Middleware dapat digunakan untuk:

- Logging.
- Authentication.
- Authorization.
- CORS.
- Request Validation.
- Recovery.
- Rate Limiting.

Contoh:

```go
func LoggingMiddleware(
    next http.Handler,
) http.Handler {
    return http.HandlerFunc(
        func(
            w http.ResponseWriter,
            r *http.Request,
        ) {
            fmt.Println(
                r.Method,
                r.URL.Path,
            )

            next.ServeHTTP(w, r)
        },
    )
}
```

### next.ServeHTTP()

```go
next.ServeHTTP(w, r)
```

Meneruskan Request ke Handler berikutnya.

Tanpa pemanggilan tersebut, Middleware dapat menghentikan alur Request sebelum mencapai Handler berikutnya.

### Fungsi CORS

CORS (Cross-Origin Resource Sharing) adalah mekanisme berbasis HTTP Header yang mengatur apakah Browser mengizinkan suatu halaman web mengakses resource dari Origin berbeda.

### Access-Control-Allow-Origin

Menentukan Origin yang diizinkan.

```go
w.Header().Set(
    "Access-Control-Allow-Origin",
    "http://localhost:3000",
)
```

### Access-Control-Allow-Methods

Menentukan HTTP Method yang diizinkan.

```go
w.Header().Set(
    "Access-Control-Allow-Methods",
    "GET, POST, PUT, DELETE, OPTIONS",
)
```

### Access-Control-Allow-Headers

Menentukan Request Header yang diizinkan.

```go
w.Header().Set(
    "Access-Control-Allow-Headers",
    "Content-Type, Authorization",
)
```

### OPTIONS dan Preflight

Browser dapat mengirim OPTIONS Request terlebih dahulu untuk memeriksa apakah Request Cross-Origin diperbolehkan.

```go
if r.Method == http.MethodOptions {
    w.WriteHeader(http.StatusNoContent)
    return
}
```

`return` digunakan agar Request OPTIONS tidak diteruskan ke Handler berikutnya.

## 12.1. Inventory dengan Goroutine dan Mutex

Tujuan:

- Mengelola Stock Inventory.
- Menjalankan beberapa Goroutine.
- Menghindari Race Condition.
- Menggunakan WaitGroup untuk menunggu pekerjaan.

Implementasi konsep:

```go
type Inventory struct {
    Stock int
    mu    sync.Mutex
}

func (inventory *Inventory) AddStock(
    amount int,
    wg *sync.WaitGroup,
) {
    defer wg.Done()

    inventory.mu.Lock()
    defer inventory.mu.Unlock()

    inventory.Stock += amount
}
```

Hasil latihan:

- 5 Goroutine.
- Setiap Goroutine menambahkan 10 Stock.
- Total Stock bertambah 50.
- Mutex melindungi akses terhadap Stock.

## 12.2. Worker dengan Context dan Select

```go
func worker(ctx context.Context) {

    case <-time.After(3 * time.Second):

    }
}
```
